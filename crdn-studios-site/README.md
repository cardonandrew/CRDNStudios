# CRDN Studios — website upload package

The complete website as separate files (this is the version where the songs actually play — real audio files instead of one packed file):

- `index.html` — the page
- `assets/` — the 12 demo songs the page plays:
  - under-pressure.mp3
  - grace.mp3
  - remedy.mp3
  - existence.mp3
  - time.mp3
  - mid-october.mp3
  - hypnotized.mp3
  - infliction.mp3
  - crash.mp3
  - solemnly-swear.mp3
  - cant-sleep.mp3
  - torture.mp3

## Upload to GitHub (repo: cardonandrew/CRDNStudios)

1. Unzip this package.
2. In the repo, click **Add file → Upload files** and drag in `index.html` AND the whole `assets` folder together (Chrome keeps the folder structure). Commit.
   - If the folder drag doesn't work: upload `index.html` first, then open your `assets` folder in the repo, click **Add file → Upload files** there, and drag in the 12 mp3s.
3. The site is live at https://cardonandrew.github.io/CRDNStudios/ (give it a minute after the commit).
4. Optional cleanup: delete the old `CRDN.html` from the repo — it's the broken-audio version and nothing will link to it.

## Updating later

Ask Muse for a fresh package, then re-upload the same way (files overwrite).
